# 擬真海浪

以 WebGL2 即時模擬的擬真海洋網站。海面由 FFT（快速傅立葉轉換）海洋頻譜在 GPU 上計算，不使用任何外部函式庫。

## 功能

- **FFT 海洋模擬**：採用 JONSWAP 頻譜與 Donelan-Banner 方向分布，四層不同尺度（2000 m、250 m、17 m、5 m）疊加，看不出重複圖樣。
- **湧浪**：可獨立設定湧浪高度、方向與週期（8～18 秒），和本地風浪交錯成真實的海況。湧浪採尖峰較窄的頻譜與集中的方向分布，波峰長而規律；振幅固定、相位隨機，畫面上的浪高會符合設定。
- **擬真著色**：考慮多重散射與臭氧吸收的大氣散射天空、Fresnel 反射、GGX 太陽與月亮高光、浪峰背光的次表面散射、遠處依坡度變異自動加大粗糙度。
- **時段與天氣**：
  - **時間**：0～24 小時任意調整，太陽依北回歸線（北緯 23.5°）春分那天的軌跡東升西落，日落後有暮光與地球陰影。預設視角朝向西南方，傍晚可以看到夕陽沉入海面。
  - **夜晚**：星空跟著天球轉動，上弦月傍晚 6 點掛在正南方、午夜前落入西方海面，月面依太陽方向畫出盈虧，海面上有月光倒影；沒有月亮時只剩星光與微弱的夜空底光。
  - **縮時播放**：一秒約十分鐘，約兩分半鐘看完一整天。
  - **雲量**：一層高 1500 公尺、隨風飄移的雲，會在海面投下雲影；雲量越高越接近陰天，夕陽時雲底會被染成橘紅色。
  - **能見度**：1～50 公里，能見度低時遠方的海面、天空與太陽都隱沒在霧中。
  - **自動曝光**：依天空亮度調整曝光，只做部分適應，夜晚的畫面仍然比白天暗，但看得清楚月光下的海面。
- **白浪泡沫**：以海面擠壓程度（Jacobian）判斷浪頭，泡沫會殘留並慢慢消散；覆蓋率依風速參考 Monahan 經驗式。
- **暴風效果**：風速超過約 14 m/s（蒲福 7 級）時，碎浪留下的泡沫被風拉成沿風向的條紋，浪頭噴出被風吹散的飛沫；風越強條紋越密、飛沫越多，到 10 級（約 25 m/s）海面一片白。飛沫逆光時會透出陽光的顏色，在雲影下變暗、在霧中變淡。
- **浮標**：在 GPU 上取樣浮標所在位置的海面，讓它隨浪起伏、傾斜，頂端燈號每 4 秒閃一次。
- **自由視角**：
  - **環繞浮標**：拖曳環繞浮標，滾輪或雙指拉近拉遠，可以從貼近海面一路拉到高空俯瞰。鏡頭會依讀回的海面高度自動抬高，不會沒入浪中。
  - **船上視角**：鏡頭架在一艘隨浪起伏、左右搖晃的船上，可以拖曳環顧、縮放視野。浪大時船也會變大（甲板較高）。
  - 鍵盤也能操作（畫面取得焦點時）：方向鍵轉動視角，＋／－縮放，0 重設；雙擊畫面回到預設視角。
- **海浪音效**：以 Web Audio 即時合成底噪、浪潮起伏、碎浪聲與風聲，節奏跟著浪的週期、強度跟著浪高變化；風聲隨風速增強並有陣風起伏，暴風時還有呼嘯聲。
- **參數控制面板**：可調整時間、雲量、能見度、風速、風向、浪高倍率、浪尖銳度、湧浪高度／方向／週期、白浪泡沫、海水顏色、音量與渲染品質，並顯示有效波高（風浪與湧浪合計）與尖峰週期（能量最集中的週期）。
- **自動畫質**：依實際幀率調整渲染解析度，解析度降到底仍不夠順時再降低畫質等級（海面網格與 FFT 尺寸）。若降低後沒有變快（例如螢幕更新率鎖在 30 fps），會還原並停止調整。
- **效能資訊**：面板中可展開查看顯示卡型號、目前畫質、渲染解析度、模擬與網格大小，方便比較不同裝置。
- **HDR 後製**：多重取樣抗鋸齒、自動曝光、光暈（bloom）、ACES 色調映射。

## 執行方式

網站使用 ES module 並以 `fetch` 載入 shader，必須透過網頁伺服器開啟，直接雙擊 `index.html` 無法執行。

```bash
python3 -m http.server 8000
```

接著用瀏覽器開啟 <http://localhost:8000>。

也可以直接用 GitHub Pages 發佈：在儲存庫的 **Settings → Pages** 選擇 `main` 分支的根目錄即可。

### 瀏覽器需求

需要支援 WebGL2 與 `EXT_color_buffer_float` 的瀏覽器，例如最新版的 Chrome、Edge、Firefox 或 Safari（iOS 15 以上）。畫質預設為「自動」，電腦從「高」、手機與平板從「中」開始，再依實際幀率調整；也可以在面板手動選擇高、中、低。

### 測試

```bash
node --test
```

會執行 `tests/` 中的單元測試（自動畫質的判斷邏輯；湧浪的波高換算、方向分布與各層波數分界；視角控制與地平線位置；太陽、月亮與天球的運行；雲量與能見度的換算；大氣穿透率與光源；強風效果的強度），需要 Node.js 18 以上。

### 除錯模式

網址加上 `?debug`（例如 `http://localhost:8000/?debug`）會開放 `window.__ocean` 除錯介面，可暫停畫面、讀取海況統計值、模擬貼圖、海面取樣結果與目前的光源與天氣（`getEnvironment`），並直接操作視角控制（`rig`）、天空（`sky`）、浪花飛沫（`spray`）與音效（`audio`）；`getFrameCount` 可用來等待新的一幀畫完。

## 技術筆記

1. **初始頻譜**（`spectrum-init.frag`）：對每個波向量 k 計算風浪（JONSWAP × Donelan-Banner）與湧浪（尖峰較窄的 JONSWAP × cos²ˢ 方向分布）的頻譜，風浪乘上高斯亂數、湧浪只取隨機相位，得到 h0(k)。只在海況參數改變時執行，所以拖動滑桿也很順暢。每一層只負責自己那段波長：2000 m 的區塊負責 125 m 以上的長浪（主要是湧浪），其餘三層依序負責較短的波。
2. **時間演進**（`spectrum-time.frag`）：h(k, t) = h0(k)·e^{-iωt} + conj(h0(-k))·e^{iωt}，同時算出水平位移與各個偏導數，兩兩打包成複數，一次 IFFT 得到 8 個實數場。頻率量化成基頻的整數倍，動畫每 1000 秒無縫循環。
3. **IFFT**（`fft.frag`）：Stockham 基數 2 演算法，水平、垂直各 log2(N) 回合。
4. **整理**（`assemble.frag`）：輸出位移、法線用的導數、坡度平方（mipmap 後估計遠處粗糙度），並以 Jacobian 追蹤泡沫。
5. **海面網格**（`ocean.vert`）：螢幕空間的投影網格，一路延伸到 20 公里外的地平線，依網格間距挑選 mipmap 層級以免遠處閃爍。網格頂端對齊地平線在畫面上的位置；畫面傾斜時取地平線的最高點，避免傾斜的地平線附近露出破洞。
6. **海面取樣**（`probe.frag`、`wave-probe.js`）：把鏡頭與船所在位置的海面位移與坡度畫到一張小貼圖，用 PBO 搭配 fence 在之後幾幀非同步讀回，不會讓 GPU 停下來等。取樣時依物體大小挑選 mipmap 層級，船只反應大浪、不會被小波紋晃得亂抖。
7. **大氣**（`atmosphere.glsl`、`sky-transmittance.frag`、`sky-multiscatter.frag`、`sky-precompute.frag`）：參考 Bruneton（2017）與 Hillaire（2020），載入時先算好穿透率與多重散射兩張查找表；時間改變時沿視線光線步進，累加太陽與月光的單次散射與多重散射，存成經緯度貼圖。光源在地平線下時，被地球擋住的空氣只剩多重散射，形成暮光與地球陰影；臭氧吸收讓日落後的天頂偏藍。拖動時間或縮時播放時，大氣貼圖最多每 0.15 秒重算一次。
8. **雲與霧**（`clouds.glsl`、`sky-clouds.frag`）：雲是一層以 fBm 噪音產生的 2D 雲，雲量依實測的噪音分布換算成門檻（`weather.js`），雲量 30% 時看起來約三成的天空有雲。沿光源方向再取一次密度估計自身遮蔽，並有銀邊與厚度造成的明暗；遠處的雲換成平均密度，地平線附近是一層朦朧的雲。每幀把雲與霧合成到一張含雲的天空貼圖，海面反射、環境光、遠處的霧與曝光都用它；天空背景則以全解析度另外繪製。能見度依 Koschmieder 公式換算消光係數，低於晴天時另外加上一層 1 公里厚的霧，天空、太陽與照到海面的光都會被削弱。
9. **星空與月亮**（`sky.frag`）：星星以立方體六個面的格子隨機放置，跟著天球轉動，只在太陽落到地平線下、天空夠暗時出現。月面用重建的球面法線與太陽方向計算盈虧，表面加上較暗的月海。
10. **浪花飛沫**（`spray-update.frag`、`spray.vert`、`spray.frag`）：4096 顆 GPU 粒子，位置與速度存在浮點貼圖裡，每幀以全螢幕繪製更新。死掉的粒子在鏡頭前方隨機挑點，四層疊加的 Jacobian 低於 0.66（實測約 2% 的海面）的浪頭才噴出；之後被風拖曳、受重力落下，落回海面或壽命到了就死掉。每顆粒子畫成沿飛行方向拉長的方塊，光照（水滴的前向散射、雲影、大氣透視）在頂點算好，以預乘 alpha 混合，只做深度測試、不寫入深度。畫質「中」與「低」只畫一半與四分之一的粒子。
11. **泡沫條紋**（`ocean.frag`）：把泡沫紋理沿風向拉長成細長的線，再用低頻噪音與泡沫細紋打散，風越強條紋越寬越密，並跟著表層海流（風速的 3%）往下風處漂；拉長的紋理在遠處容易產生摩爾紋，所以隨距離淡出。
12. **曝光**（`common.glsl` 的 `autoExposure`）：取天空貼圖平均亮度（最小一層 mipmap）的 -0.75 次方，只做部分適應，在 GPU 上直接計算、不需讀回。光暈在曝光後才取門檻，白天與夜晚的光暈強弱一致；浮標燈號在畫面上的亮度固定。
